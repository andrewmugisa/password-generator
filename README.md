# 🔐 Password Generator Extension

A simple, secure, and open-source browser extension that generates strong passwords on demand—without storing or transmitting any data.

## 🌐 Live Demo

Try it here:
👉 [https://andrewmugisa.github.io/password-generator/](https://andrewmugisa.github.io/password-generator/)

---

## 🚀 Features

* Generate strong, random passwords instantly
* Provides **2 password options per request**
* No data storage or tracking
* No API calls — fully offline functionality
* Lightweight and easy to use

---

## 📦 Installation Guide (Manual Setup)

Follow these steps to install the extension locally in Chrome:

### 1. Download the Project

* Download the ZIP file from the project page or repository

### 2. Extract Files

* Extract the ZIP file to a location on your computer

### 3. Open Chrome Extensions

* Go to:

  ```
  chrome://extensions/
  ```

### 4. Enable Developer Mode

* Toggle **Developer Mode** (top right corner)

### 5. Load the Extension

* Click **“Load unpacked”**
* Select the correct folder:

  ```
  password-generator-main/password-generator-main
  ```

⚠️ **Important:**
Do NOT select subfolders like `.vscode`
If you see the error:

> "Manifest file is missing or unreadable"

…it means the wrong folder was selected.

---

### 6. Pin the Extension

* Click **“Details”** on the extension
* Click **“Pin to toolbar”**

---

### 7. Start Using

* Click the extension icon in the browser toolbar
* Generate and copy secure passwords instantly

## 🔒 Security & Privacy

Your privacy is fully respected:

* ❌ No API calls
* ❌ No data collection
* ❌ No password storage
* ✅ Passwords are generated locally in your browser

Each request generates new passwords that are **not saved anywhere**.
